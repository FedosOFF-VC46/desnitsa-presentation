# Десница — презентация ВКР

Интерактивная презентация защиты темы магистерской выпускной квалификационной работы Федосова Даниила Станиславовича.

**Тема:** «Модель доверенной инфраструктуры верификации происхождения и авторства гуманитарного цифрового контента в условиях распространения генеративного искусственного интеллекта».

14 основных экранов и дополнительная архитектурная карта на экране 15.

## Просмотр

https://fedosoff-vc46.github.io/desnitsa-presentation/

Перелистывание: стрелки, пробел или Page Down / Page Up. `F` — полный экран, `N` — текст выступления, `O` — обзор экранов, `P` — пауза анимаций. На 15-м экране доступно увеличение архитектурной карты.
